# JOB BOT

면담하고 싶은 직업의 사람과 이야기하고, 끝나면 면담 요약을 받는 한국어 웹 앱입니다.

사이트: https://gpt--job-bot-ejh.netlify.app/

## 사용 순서

1. 랜덤 인사를 확인합니다.
2. **면담하고 싶은 직업**을 입력합니다. 그때마다 무난한 한국 이름이 붙습니다.
3. 준비 중 화면에서 브라우저에 모델을 받은 뒤 면담을 시작합니다.
4. 그 사람의 입장에서 면담합니다. 채팅 중 욕설은 그 자리에서 차단됩니다.
5. 위쪽 **종료**를 누르면 질문과 응답, 해석이 남고 기록에 저장됩니다.

## 로컬에서 보기

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 을 엽니다. Chrome 또는 Edge가 필요합니다.

## 기술

- 정적 HTML / CSS / JavaScript. GitHub Pages에서 그대로 열립니다.
- 텍스트 생성은 브라우저의 WebLLM (Qwen2.5 3B) 입니다. API 키와 서버가 없습니다.
- 첫 면담 때 모델이 기기에 내려받아집니다.
